# Central Dispatch Payroll Management System - Frontend

A production-quality Windows/Desktop-first Bermuda Payroll Management System built with React 18, Vite, TypeScript, Tailwind CSS, Lucide React, Recharts, React Hook Form, and Zod.

## Features
- **Dashboard**: KPI cards, Recharts payroll distribution & leave charts, weekly staff schedule summary.
- **Employee Management**: Filterable employee directory, add/edit modal, 8-tab profile with sensitive field masking.
- **Staff Contacts**: Searchable directory with emergency contact details & editing.
- **Weekly Schedules**: Mon-Sun shift matrix with auto-calculating hours & persistent notes.
- **Leave Calendars**: Side-by-side Sick Time and Holiday calendars with date toggling.
- **Payroll Console**: Weekly payroll entry, overtime calculation, net pay computation, CSV exports, and approval workflow.
- **Payslips & Email**: Official Bermuda letterhead payslips with simulated Microsoft 365 email dispatch.
- **Reports & Security**: 8 Payroll reports, system action audit trail, RBAC permissions (Super Admin, Admin, Staff), user accounts, and Bermuda settings.

## Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```
